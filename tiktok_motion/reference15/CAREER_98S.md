## Build
Requires Python with Pillow, numpy, scipy, FFmpeg and the `espeak` binary. Locally, create the extension at `tiktok_motion/reference15/longform.py` on the isolated branch. It reuses the `reference15.produce` primitives. Use local chunk-render helper `chunks.py` for environments where rendering 98s in one process exceeds task time limits.

```sh
python -m unittest tiktok_motion.reference15.test_longform -v
python -m tiktok_motion.reference15.longform --preview-seconds 4 --output /tmp/career4.mp4
python -m tiktok_motion.reference15.longform --output /tmp/career98.mp4
```
