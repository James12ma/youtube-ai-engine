# Existing premium engine integration

Preserves main's verified Director fixes. Imports the actual existing `tiktok_motion` source, including the Blender Focus scene, Remotion components, fonts, reference renderers and owner-script parser.

## Phone control
- `/script en <complete script>` (or `/video en <complete script>`): exact narration, separate paragraphs become scenes, native English Kokoro, measured speech timeline, Remotion premium typography/animated glossy layouts, native-token captions, private Telegram MP4 + 15-second voice audition.
- Optional `voice=am_michael` after `en`; default `af_heart`.
- Structured JSON script is accepted inline: title, English language, scenes with narration, kind, on_screen and up to six items. Scene kinds: kinetic, cards, process, ui, timeline, chart (category labels only; no invented metrics).
- `/motiontest`: registered career sample through the same private script pipeline.
- `/premium3d`: explicit existing Blender Cycles + Remotion Focus 13-second renderer, original score, potentially several hours on free CPU. This is a fixed reference composition, not arbitrary subject-to-3D generation.
- `/queue` and `/cancel <id>` keep their existing behavior.

The user's source is SHA256-bound and never rewritten. Workflow inputs contain only a private Telegram file reference and metadata, not plaintext script. Duplicate owner messages do not dispatch duplicate jobs. GitHub outages remain queued with backoff. Only the authenticated owner in a private chat is served.

English shared narration now uses Kokoro's American English phonemizer directly, without the rejected multilingual Chatterbox + Spanish reference combination. Spanish narration is preserved. Existing screen-tutorial renderers report the actual voice backend.

A native-token caption duration is generated by Kokoro, not WhisperX forced alignment or independent ASR. Technical checks do not certify human pronunciation, editorial quality or factual accuracy. Voice approval and publishing remain false. Freeform visual directions remain review requirements; templates do not implement arbitrary requested footage or real software clicks.

No YouTube upload, paid API, paid GPU, new service or project restart. The existing Cloudflare Worker and D1 queue are reused.
